# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/04e6cef8-b58b-4b07-b579-320ae05d7941

## Run Locally

**Prerequisites:** Node.js on Windows


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Start the app: `npm run dev`

## Timestamped transcription JSON

Phase 2 imports a transcription JSON file generated by your transcription tool. The JSON must contain an exact `duration` and a word-level `words` array. Each word requires `start`, `end`, and either `word` or `text`. The app groups those timestamps into the custom scene duration selected in Settings while preserving silent windows and a shorter final scene. The fresh-project default is 6 seconds, and any duration from 0.1 to 600 seconds is accepted, including decimals.

## Project persistence and recovery

Project bodies are stored once in IndexedDB rather than duplicated in `localStorage`. Existing `facility_engine_*` projects migrate automatically on first launch and are removed from legacy storage only after the IndexedDB transaction succeeds. Direction and prompt generation creates a durable checkpoint after every 30-scene batch, including the next resumable scene and run status.

The header reports the actual save state. If browser storage cannot accept a checkpoint, generation pauses and the current in-memory project remains downloadable as a recovery JSON. The project library reports browser-provided storage usage and individual project sizes. Prompt Studio paginates large projects to 30 editable prompts per page, and a cross-tab warning appears when the same project is open in more than one tab.
